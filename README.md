# دستنویس

رابط کاربری فارسی و واکنش‌گرا برای تبدیل تصویر دست‌نوشته به متن قابل ویرایش.

## اجرا

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173` را باز کنید.

> نسخه فعلی یک نمونه رابط کاربری است و نتیجه تشخیص متن را برای نمایش جریان تجربه کاربری شبیه‌سازی می‌کند. برای استفاده عملی، تابع `processFile` را به سرویس OCR متصل کنید.
